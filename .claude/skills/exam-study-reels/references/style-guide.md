# 디자인 값

공통: 1080×1920, 30fps, 릴스 안전영역 **위 288 ~ 아래 1248px, 좌우 120px**(HyperFrames `check --safe-zone reels`). 자막 하단은 y=1240(`bottom:680px`). 중요한 글자는 모두 이 안.

## v1 카드 테마
- 바탕색: `GROUND` 환경변수(기본 크림 `#fff6e5`). 얼룩 두 개 `BLOB_A`(좌상) `BLOB_B`(우하) 기본 보라/민트.
  - 크림: 기본값(조사론). 하늘색: `GROUND='#e3f0ff' BLOB_A='rgba(255,201,60,0.34)' BLOB_B='rgba(108,77,246,0.16)'`(인간행동).
  - 다른 영역 예: 연분홍 `#fde7ea` + 민트 얼룩, 라벤더 `#ece7ff` + 노랑 얼룩. 글자 대비(흰 글자 on 카드색 3:1 이상)를 해치지 않는 연한 색만.
- 폰트: Black Han Sans(제목) + Noto Sans KR 700(본문). 캐릭터 다람쥐 `강점이`(주황), 카드 행마다 색 다른 동물 얼굴.
- 레이아웃: HUD 태그 y296 · 헤더칩 y368 · 카드 y446~1000 · 자막 하단 1240.

## v2 종이·주황 모션 (레퍼런스: 양피지 바탕 + 굵은 헤드라인 + 3D 캐릭터 + 다크 목업 + 도장)
- 바탕: `scripts/paper.py <출력.jpg> "R,G,B"` — 보로노이 면(구김) 질감. 기본 세이지 `212,230,204`. 원하는 종이색을 RGB로(예 베이지 `236,224,200`, 연하늘 `208,224,240`, 연분홍 `244,220,218`).
  - 바탕색이 어두워지면 글자 대비가 깨지니 밝은 색(채도 낮게)만.
- 색: 주황 `#dc480e`(채움), 주황 글자 `#c43d08`, 잉크 `#141414`, 크림 카드 `#f5f0e3`.
- 폰트: Noto Sans KR **900**(헤드라인·카드 제목) / 700(본문).
- 레이아웃: HUD(주황 알약) y292 · 헤드라인 y352(2줄, 54px/훅 64px) · 패널 y506~1010 · 자막 하단 1240.
- 패널: 카드 장면=반투명 흰 패널+흰 알약 행(주황 번호 배지, ○는 검정 ✕는 주황 원), 예시/퀴즈=다크(#141414) 패널.
- 캐릭터: SVG 여자아이(주황 비니)가 주황 공에 앉아 줄에 매달려 **좌우 ±7°로 흔들림**(훅 큰 크기, 퀴즈 작은 크기). 줄은 글자/패널 **뒤**.
- 모션: 헤드라인 슬라이드업, 패널 팝, 행 좌우 슬라이드, 도장 쿵(스케일 1.7→1, 회전), 패널 둥둥(정지 3초 방지), 배경 천천히 이동.

## 음성·음악
- edge-tts `ko-KR-SunHiNeural`, `rate=+0%`, `pitch=-3Hz`(차분한 여성). 다른 음성은 `build_ep.py`의 `Communicate(...)` 인자만 교체.
- 앞뒤 무음 제거(silenceremove) 후 길이로 타이밍 계산. 속도 가공은 하지 않는다(대본을 줄이는 쪽이 낫다).
- 음악: `music.py`로 합성한 코드 진행 + 가벼운 비트. 해설이 나오면 sidechain으로 자동 감소, 마지막 2초 페이드아웃.

## 캐릭터 옵션 (v2, `CHARACTER`)
- `swing`: 줄에 매달려 ±7°로 흔들리는 여자아이(훅 큰 크기·퀴즈 작은 크기). 줄은 글자 뒤.
- `cat`: 책 3권 위에 앉은 안경 고양이. 몸통 위아래 까딱, **꼬리 좌우 흔들기, 손 흔들기, 눈 깜빡임**. 퀴즈 장면에서는 위에서 튀어 내려옴.
- 새 캐릭터를 추가하려면 `build_v2.py`에 `xxx_markup(sid, cx, by, s)`(SVG 문자열) + `xxx_js(...)`(GSAP 모션 목록)를 만들고 hook/cta 분기에 연결. **GSAP `svgOrigin`은 확대·이동된 부모 그룹의 '로컬 좌표'로 읽힌다**(전역 좌표를 넣으면 꼬리가 날아감).

## 종이 색 예시 (`paper.py <out.jpg> "R,G,B"`)
세이지 `212,230,204`(실천론) · 연분홍 `246,216,222`(실천기술론) · 베이지 `236,224,200` · 연하늘 `208,224,240`. 밝고 채도 낮은 색만(어두우면 글자 대비 깨짐).
