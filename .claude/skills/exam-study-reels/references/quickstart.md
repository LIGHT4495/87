# 다음 회차 기출 → 릴스 빠른 시작 (한 장)

## 0. 준비물
- 문제지 PDF + **공식 정답표**(꼭 대조: 정답을 추정하면 틀릴 수 있어요. 지역사회복지론 55번 사례)
- 네트워크: `speech.platform.bing.com` 허용(음성). 끝나면 제거.

## 1. 순서
1. **문제 읽기** — PDF를 20쪽 이하씩 Read. 영역 경계 확인(예: 3교시 1~25 정책론 / 26~50 행정론 / 51~75 법제론).
2. **정답 확정** — 정답표로 모든 문항 검증. 확신 낮은 문항·개정 가능성 큰 법령 숫자는 제외하고 알릴 것.
3. **편 구성** — 25문항 ≈ 7~10편. 개념 쌍(비교) 단위. 한 편 = 후킹 → 카드(비교/versus) → "틀림!" 도장 → 퀴즈 + 정답 공개.
4. **대본 작성** — `examples/episodes_<영역>.py` (스키마 `references/schema.md`). 마지막 줄에 `pause=2.3`, cta에 `reveal=dict(line=정답줄, answer=버튼번호)`.
5. **환경 설정** — `examples/presets.md`의 영역별 프리셋(캐릭터·색·스타일)을 `env_xxx.sh`로 저장. 종이: `scripts/paper.py out.jpg "R,G,B"`.
6. **파이프라인** — `lint_content.py` → `tts` → `html` → `audio` → `check` → `snapshot`(눈으로 2~3편 확인) → `render`.
7. **전달** — 완성되는 대로 SendUserFile. 영역별/교시별 zip, 캡션·고정 댓글 파일 포함.

## 2. 함정 모음
- 컨테이너가 약 13~15분마다 재시작되면 백그라운드 렌더링이 끊긴다 → `setsid nohup`으로 실행하고, **없는 mp4만 골라 다시 렌더링**하는 스크립트(resume)를 쓴다. 결과는 매번 파일로 확인.
- 자막 3줄 초과 / 글자 폭 초과는 lint가 잡는다(통과할 때까지 수정).
- 장면(scene)의 lines는 시간 순서대로 겹치지 않게. exam이 앞 줄 설명까지 포함하려면 `lines=[앞줄, stamp줄]`.
- 렌더링은 3개 병렬, 편당 2~4분. 한꺼번에 끝낼 수 없으니 순서(영역별)를 정해 보낸다.
